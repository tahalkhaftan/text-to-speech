# Text-to-Speech
شما می تونید با رفتن توی لینک زیر به همراه فیلتر شکن از سایت ما به صورت اینترنتی بازدید کنید
https://text-to-speech-skcg.onrender.com/
یک پروژه‌ی ساده‌ی **تبدیل متن به صدا (Text-to-Speech)** با استفاده از
Python، Flask و Edge TTS.

این برنامه به کاربر اجازه می‌دهد: - زبان فارسی یا انگلیسی را انتخاب
کند. - صدای مرد یا زن را انتخاب کند. - متن موردنظر را وارد کند. - متن را
به فایل صوتی `voice.mp3` تبدیل کند. - صدای ساخته‌شده را داخل سایت پخش
کند. - فایل صوتی را دانلود کند.

## فایل requirements.txt

برای اینکه نصب پروژه روی یک سیستم جدید ساده‌تر باشد، فایل
`requirements.txt` شامل موارد زیر است:

``` text
Flask>=3.0
edge-tts>=7.0
```

در یک سیستم جدید می‌توان تمام وابستگی‌ها را با یک دستور نصب کرد:

``` powershell
python -m pip install -r requirements.txt
```

این دستور باید در پوشه‌ای اجرا شود که فایل `requirements.txt` در آن قرار
دارد.

## اجرای پروژه

ابتدا وارد پوشه‌ی پروژه شوید. برای مثال:

``` powershell
cd "C:\path\to\text_to_speech"
```

سپس برنامه را اجرا کنید:

``` powershell
python app.py
```

بعد از اجرای Flask، در مرورگر وارد آدرس زیر شوید:

``` text
http://localhost:5000
```

یا:

``` text
http://127.0.0.1:5000
```

تا زمانی که `app.py` در حال اجرا باشد، سایت نیز فعال است. با متوقف کردن
برنامه، سایت دیگر سرویس نمی‌دهد.

برای متوقف کردن Flask در PowerShell معمولاً می‌توانید از:

``` text
Ctrl + C
```

استفاده کنید.

ما برای راحتی کار شما یک فایل rog.bat قرار داده ایم
پس از فعال سازی app.py روی rog.bat کلیک کنید تا وارد سایت مورد نظر بشوید

## دسترسی از دستگاه‌های همان شبکه

`localhost` فقط روی همان کامپیوتری که برنامه روی آن اجرا شده قابل
استفاده است.

اگر Flask برای دسترسی شبکه‌ی محلی تنظیم شده باشد، دستگاه‌های متصل به همان
Wi-Fi/LAN می‌توانند با IP داخلی کامپیوتر به سایت دسترسی داشته باشند.

برای مشاهده‌ی IP سیستم در Windows:

``` powershell
ipconfig
```

برای مثال اگر IPv4 کامپیوتر:

``` text
192.168.7.105
```

باشد، آدرس سایت در شبکه‌ی محلی می‌تواند به شکل زیر باشد:

``` text
http://192.168.7.105:5000
```

برای این حالت Flask باید روی رابط شبکه گوش دهد، مثلاً:

``` python
app.run(host="0.0.0.0", port=5000, debug=False)
```

ممکن است Windows Firewall نیز برای شبکه‌ی Private نیاز به اجازه داشته
باشد.

توجه: IPv4 را از بخش Wi-Fi بردارید
------------------------------------------------------------------------

## دسترسی از خارج از شبکه

آدرس‌هایی مانند:

``` text
192.168.x.x
10.x.x.x
172.16.x.x
```

آدرس‌های خصوصی هستند و نمی‌توان آن‌ها را مستقیماً برای فردی در یک کشور یا
شبکه‌ی دیگر فرستاد.

برای دسترسی از اینترنت، باید یکی از روش‌های مناسب انتشار سرویس استفاده
شود، مانند:

-   Tunnel عمومی
-   Public IP + Port Forwarding، در صورتی که شرایط شبکه و ISP اجازه دهد
-   استقرار برنامه روی یک سرور یا سرویس Hosting

در صورت استفاده از Tunnel، معمولاً Flask همچنان روی کامپیوتر اجرا می‌شود و
Tunnel یک آدرس عمومی HTTPS به آن متصل می‌کند.

اگر `app.py` یا Tunnel متوقف شود، سرویس عمومی نیز دیگر کار نخواهد کرد.

------------------------------------------------------------------------

## نکته‌ی امنیتی

برای سایتی که از اینترنت قابل دسترسی است، Flask را با Debug Mode فعال
منتشر نکنید.

به جای:

``` python
app.run(debug=True)
```

از تنظیمی مانند این استفاده کنید:

``` python
app.run(host="127.0.0.1", port=5000, debug=False)
```

اگر دسترسی LAN نیز لازم است:

``` python
app.run(host="0.0.0.0", port=5000, debug=False)
```

برای استفاده‌ی جدی و عمومی، بهتر است از یک WSGI server مناسب و تنظیمات
امنیتی مربوط به محیط production استفاده شود.

## نیاز به اینترنت

`edge-tts` برای تولید صدا به سرویس آنلاین متصل می‌شود. بنابراین سیستمی که
`app.py` را اجرا می‌کند باید هنگام تولید صدا به اینترنت دسترسی داشته
باشد.

اگر اینترنت قطع باشد یا دسترسی به سرویس TTS برقرار نشود، تولید فایل صوتی
ممکن است با خطا مواجه شود.

## رفع خطاهای رایج

### `ModuleNotFoundError: No module named 'flask'`

اجرا کنید:

``` powershell
python -m pip install flask
```

### `ModuleNotFoundError: No module named 'edge_tts'`

اجرا کنید:

``` powershell
python -m pip install edge-tts
```

### requirements.txt پیدا نمی‌شود

اگر خطایی مانند زیر مشاهده کردید:

``` text
Could not open requirements file
```

ابتدا با `cd` وارد پوشه‌ی پروژه شوید و سپس دوباره دستور نصب را اجرا کنید:

``` powershell
python -m pip install -r requirements.txt
```

### سایت با localhost روی گوشی باز نمی‌شود

`localhost` در گوشی به خود گوشی اشاره می‌کند، نه کامپیوتر. برای دستگاه‌های
یک شبکه باید از IP داخلی کامپیوتر و تنظیم مناسب Flask استفاده شود.
